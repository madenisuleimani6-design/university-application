# AMIS Backend

This backend starter exposes authentication, student, course, finance, and accommodation endpoints.

## Run locally

```bash
cd backend
mvn spring-boot:run
```

## Endpoints

- POST /api/auth/login
- GET /api/students
- POST /api/students
- GET /api/courses
- POST /api/courses
- GET /api/payments
- POST /api/payments
- GET /api/accommodation
- POST /api/accommodation
